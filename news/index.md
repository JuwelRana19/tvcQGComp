# Changelog

## tvcQGComp 0.0.0

- Initial public GitHub release.
- Supports quantized static intervention scenarios for time-varying
  exposure mixtures.
- Provides model-based HR, RR, and RD main-effect estimates from pooled
  person-time or final-risk meta models.
- Includes cluster bootstrap support for confidence intervals.
- Includes a simulated longitudinal survival dataset and reproducible
  example analysis.
- Includes cumulative-incidence and survival trajectory plots, including
  an optional average line across quantized scenarios.
- Includes run and drift diagnostics for model checking.
